# Xagros의 한글화 패치 — 나리키리 던전 2 v0.9d 테스트판

일본어 원본 ROM에 한 번만 적용합니다. FFR 패치를 별도로 구하거나 먼저 적용할 필요가 없습니다.

입력: AN9J 일본어 원본, 8,388,608 bytes
SHA-256: `a92c0f6dbb5c013b47b7178e23d81663e3952a10df7b1f68967ebf7bb3b98eb7`

압축을 푼 폴더에서 Python 3.10 이상으로 실행합니다. 추가 패키지는 필요하지 않습니다.

```powershell
python apply_japanese_patch.py "일본어 원본.gba" --output "Xagros_Narikiri2_KOR_v0.9d_test.gba"
```

결과: 13,107,200 bytes
SHA-256: `e9dbed3a744100b02ec1e0a67c153dda850d5c95fcfe32803008397ae6c9a04a`

입력·패치·결과의 해시를 검사하며 기존 파일을 덮어쓰지 않습니다. 일반 BPS 적용 도구로도 동봉 BPS를 적용할 수 있지만 결과 SHA-256을 확인하십시오. BETA2/BETA3나 이미 한글화한 ROM을 입력하면 안 됩니다.

v0.9c의 번역·저장·글꼴 수정을 유지하고, 시작 화면을 원본의 Namco / Produced by NAMCO로 복구했습니다. 대열 위치 변경 시 선택 테두리가 깨지던 압축 형식 바이트도 복구했습니다. 이 버전에서 추가 대사 교정은 하지 않았습니다.

이 패키지는 패치·적용 코드·고지만 포함합니다. ROM·세이브·BIOS는 포함하지 않습니다. 사용자가 별도로 받은 테스트 세이브는 초반 진행 상태에서 아이템 156종을 각 1개 보유하고 몬스터·코스튬·인물 도감을 해금한 8 KiB 게임 저장입니다. 모든 코스튬의 소유, 기술 습득, 스토리 완료를 뜻하지 않습니다. ROM과 SAV의 파일명을 확장자를 제외하고 같게 맞추고, 원래 사용하던 세이브는 따로 백업하십시오. 이전 ROM의 강제저장(savestate)은 사용하지 마십시오.
