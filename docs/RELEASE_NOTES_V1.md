# v1.0 — Xagros의 한글화 패치 · 나리키리 던전 2

## 변경점

v1.0 후보는 최종 검증 후보 ROM과 바이트가 같습니다. 공개 v0.9d와는 바이트가 다릅니다. 한국어 타이틀/로고의 숫자 2와 ® 수정, 엔딩 스탭롤 ASCII 글꼴 복원, FFR/XAGROS 번역 크레딧과 감사 문구, 부팅 안내, 22개 장소 표기, 17개 힌트와 CP #44 머리글, 156개 아이템/142개 몬스터 설명 검토 및 대사 교정을 포함합니다.

대사 원문 대조: 본문 8,037개 고유 ID / 8,945개 바인딩, 이름/UI 1,227개. 본문 60개 ID의 98개 바인딩을 교정했습니다. 변경 상세는 검증 문서를 참조하십시오.

## 적용 대상

- 게임 코드: AN9J
- 일본어 원본: 8,388,608 bytes; SHA-256 `a92c0f6dbb5c013b47b7178e23d81663e3952a10df7b1f68967ebf7bb3b98eb7`
- 최종 ROM: 13,270,790 bytes; SHA-256 `7505ef506e4fc11e1e0f36672956627e7522d2441cedfb06a5f359e7f5bd2b50`
- BPS: 5,045,193 bytes; SHA-256 `8d4a102714dccca1228215d97ae38b55eaca7ed9b74552150d3ab6aee2fa16e6`
- ZIP / 외부 manifest: 비공개 ZIP 재적용 확인; 외부 manifest는 배포 조건 충족 후 최종 커밋에 연결

## 적용 명령

Python 3.10 이상, 추가 패키지 불필요:

```powershell
python apply_japanese_patch.py "일본어 원본.gba" --output "Xagros_Narikiri2_KOR_v1.0.gba"
```

## 저장 호환

기존 8 KiB 게임 저장은 백업 후 ROM/SAV 파일명을 확장자를 제외하고 동일하게 맞춰 사용하십시오. 이전 ROM의 savestate는 사용하지 마십시오. 구체적인 저장 시험 결과는 `verification/v1.0.json`에 기록합니다.

## 검증 범위

새 전체 체인 A/B 빌드가 같은 결과를 냈습니다. 실데이터 검사 166/166, 공개 CI 43/43, 타이틀/크레딧 6/6, 일본어 적용 7/7 통과로 기록되었습니다. v1.0 적용기 검사 7개가 통과했습니다(정상 적용/왕복, 기존 출력 보호, 변조 원본, 이미 패치된 원본, 손상 BPS, 경로 충돌, 입력 보호). 비공개 ZIP은 결정성과 새 폴더 재적용을 확인했습니다. 현재 후보의 PC mGBA에서는 화면 입력으로 혼합 이름을 지정한 새 게임의 8 KiB 저장과 두 번의 재시작, 기존 저장 및 중단 저장 복귀를 확인했습니다. 기본 이름 새 게임의 과거 자동입력 경로는 변경된 튜토리얼 대화 시점에서 멈춰 저장 완료로 판정하지 않았습니다. 공개 다운로드 재적용은 발행 후 수행합니다. 이 검사들은 실기 진행, 전체 자연 플레이 또는 모든 분기의 완주를 뜻하지 않습니다. 최종 JSON에서 각 범위와 실패·오류·건너뜀·미실행을 확인하십시오.

**USER_ATTESTED:** 사용자는 “기존 대사 번역 단계에서 부터 20시간 정도 플레이를 하였고 막히는 레벨링 구간 및 도감 확인에는 치트도 사용하였습니다. 기존 세이브 파일과 진행하는데 이상 없이 이어졌습니다”라고 보고했습니다. 추가로 OLD 2DS + DSPico + GBARunner3의 기존 저장에서 스탭롤까지 진행했다고 보고했습니다. 자동 기기 로그가 아니며, 치트를 사용한 구간을 포함합니다. 새 게임부터의 완주, 치트 없는 자연 해금, 모든 분기 완주 또는 최종 후보 해시와의 명시적 연결을 뜻하지 않습니다.

## 알려진 제한

전체 자연 플레이와 최종 ROM의 명시적 사용자 해시 연계는 확인되지 않았습니다. 대상 기기에서 새 게임·두 번의 재시작·이름 입력·중단 저장 복귀는 보고되지 않았습니다. 공개 다운로드 재적용은 발행 후 수행합니다.
