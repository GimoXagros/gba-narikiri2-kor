CP 설명 정정:
0x3AC014의 압축 형식 값 04는 게임 압축 로더가 처리하지 않는다. 30으로 원본 복구한 사실은 확인했다.
그러나 해당 CP 자산이 실제 게임에서 사용되는 메뉴/진입 경로는 확인되지 않았다.
메뉴 그림 단일/복합 로더의 직접 호출 조사에서도 44번을 지정한 경로는 발견하지 못했다.
따라서 게임 중 실제 누락 오류를 고쳤다고 단정해서는 안 되며, 미사용 잔여 자산일 가능성이 있다.
CP_복구_표시검증.png는 32x8 의상 안내 슬롯에 16x8 CP를 대입한 임시 검증 ROM 화면이다.
주변 타일이 보이는 문제는 이 임시 배치에 있으며, 실제 배포 ROM에 이 배치는 들어 있지 않다.
CP 그림 픽셀 확인은 됐으나 실제 CP 메뉴 전체 화면의 정상 동작 증거는 아니다.
