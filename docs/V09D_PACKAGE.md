# Xagros의 한글화 패치 — 나리키리 던전 2 v0.9d 공개 검증판

일본어 원본 ROM에 한 번만 적용합니다. FFR 패치를 별도로 구하거나 먼저 적용할 필요가 없습니다.

입력: AN9J 일본어 원본, 8,388,608 bytes
SHA-256: `a92c0f6dbb5c013b47b7178e23d81663e3952a10df7b1f68967ebf7bb3b98eb7`

압축을 푼 폴더에서 Python 3.10 이상으로 실행합니다. 추가 패키지는 필요하지 않습니다.

```powershell
python apply_japanese_patch.py "일본어 원본.gba" --output "Xagros_Narikiri2_KOR_v0.9d.gba"
```

결과: 13,107,200 bytes
SHA-256: `69c5a3e22e00bcacfbaaa7eb28f2efc7d06c8ef37a646ac7236bc78bf76d4012`

입력·패치·결과 해시를 검사하며 기존 파일을 덮어쓰지 않습니다. 일반 BPS 적용 도구로도 동봉 패치를 적용할 수 있지만 결과 SHA-256을 확인하십시오. BETA2/BETA3, v0.9c 또는 이전 v0.9d 테스트 롬에 추가 적용하는 패치가 아닙니다.

v0.9c의 번역·글꼴·저장 수정을 유지하며 다음을 반영했습니다.

- 타이틀의 **교환**을 **처음부터·이어하기·중단부터**와 같은 달무리 글꼴·외곽선으로 통일했습니다.
- 저장 없음, 일반 저장, 중단 저장 상태에서 메뉴 전환을 확인했습니다. 중단부터 선택 후 게임 재개와 교환 화면 진입·복귀도 검증했습니다.
- 시작 화면을 원본 **Namco / Produced by NAMCO**로 복구했습니다.
- 대열에서 위치 변경 시 선택 테두리가 깨지는 문제를 수정했습니다.

기존 8 KiB 게임 저장은 원본을 백업한 뒤 ROM과 SAV의 파일명을 확장자를 제외하고 같게 맞춰 사용하십시오. 이전 테스트 세이브도 사용할 수 있습니다. v0.5 저장 복구를 추가 적용할 필요는 없습니다. 이전 ROM의 강제저장(savestate)은 재사용하지 마십시오.

패키지는 패치·적용 코드·고지만 포함합니다. ROM·세이브·BIOS는 포함하지 않습니다. 기존 번역 기여자 FFR 팀은 `CREDITS.md`에 기재했습니다.

mGBA PC에서 검증한 프리릴리즈입니다. 실제 두 기기의 통신 교환, 실기 및 장시간 전체 진행 검증은 남아 있습니다. 이번 버전에서 추가 대사 교정은 하지 않았습니다.
