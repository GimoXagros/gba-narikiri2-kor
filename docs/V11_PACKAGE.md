# 테일즈 오브 더 월드 나리키리 던전 2 한국어화 — v1.1

일본어 원본에 직접 적용하는 8MiB 패치입니다. 사용자에게 전달한 검증본과 게임 바이트가 같습니다.

2026-10-11 사용자는 직전에 전달한 8MiB 검증본의 정상 동작을 확인하고 v1.1 공개를 요청했습니다. 이를 해당 검증본에 연결한 USER_ATTESTED 공개 범위 결정으로 기록합니다. 기기·실행 프로그램·항목별 시험 내역과 사용자가 직접 대조한 해시는 별도로 보고되지 않았습니다. 이전 v1.0의 OLD 2DS 검수 기록을 이번 버전의 실기 증거로 옮기지 않습니다.

## 적용

Python 3.10 이상과 표준 라이브러리를 사용합니다. ZIP을 새 폴더에 모두 푼 뒤 실행합니다.

```powershell
python apply_japanese_patch.py "일본어 원본.gba" --output "Xagros_Narikiri2_KOR_v1.1.gba"
```

입력은 수정하지 않은 AN9J 일본어 원본 8,388,608바이트입니다.
기존 한국어 ROM이나 이미 패치한 ROM에는 적용하지 않습니다. 적용기는 입력·패치·결과의
크기와 SHA-256을 확인하며 기존 출력 파일을 덮어쓰지 않습니다.

| 구분 | 바이트 | SHA-256 |
| --- | ---: | --- |
| 일본어 원본 | 8,388,608 | `a92c0f6dbb5c013b47b7178e23d81663e3952a10df7b1f68967ebf7bb3b98eb7` |
| 결과 ROM | 8,388,608 | `9fd341b827a8ba282781d7f8f214f2ba8641365b541564d53e9ef5267511889b` |

## 저장과 검증 범위

기존 저장은 먼저 별도 복사하여 보관하고, 시험 폴더에서 ROM과 같은 파일명으로 사용합니다.
기존 ROM·저장 파일에 덮어쓰지 마십시오. 기존의 정상 8KiB EEPROM 일반 저장과 지원되는
중단 저장, 새 게임 기본·혼합 이름 저장, 두 차례 콜드 로드를 가상 코어에서 확인했습니다.
SGM은 같은 ROM의 VBA 가상 코어와 짝인 EEPROM에서만 재개를 확인했으며, 다른 코어·
ROM 버전의 상태 호환이나 실제 VBA 프로그램의 GUI 검증을 뜻하지 않습니다.

원본 텍스트 포인터 10,172개와 문자열 시작 9,246곳을 유지하고 공유 주소 7곳을 검사했습니다.
부팅 안내·타이틀·엔딩·번역 바이트는 채택본을 보존했습니다. 전체 자연 진행·모든 분기·
통신·세부 실기 항목은 미확인입니다. 엔딩 화면 검사는 기록된 시험 분기를 사용했습니다.

고정된 가상 코어 시험의 목록 P99는 아이템 8, 도감 8, 구매 7, 판매 7, 의상 7,
캐릭터 17프레임입니다. 실기 성능을 보증하는 값은 아닙니다. 상세 범위는 `VERIFICATION.json`에
기록하며, 알려진 과거 후보의 실패를 최종 후보의 통과로 덮어쓰지 않습니다.
