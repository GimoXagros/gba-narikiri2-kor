# v0.9c — PC 도구 수정 공개 검증판

2026-09-09 사용자의 “v0.9c로 프리릴리즈바랍니다” 요청에 따라 공개하는 프리릴리스입니다. PC 검증은 완료했고 실기 검증은 대기 중입니다. 동봉한 verification/v0.9c.json은 공개 승인 이전의 PC 후보 검증 기록이며, 현재 공개 승인은 verification/v0.9c-prerelease.json에 별도로 기록했습니다.

게임 ROM과 BPS는 v0.9b와 바이트 단위로 같습니다. v0.9b ROM으로 플레이하고 있다면 새로 패치할 필요가 없습니다. 이번 변경은 쓰기 실패 시 불완전한 ROM이 남는 적용기 문제, 잘못된 manifest 허용, 포인터 집계 표기를 수정합니다. 번역이나 저장 코드의 추가 변경은 없습니다.

정확한 FFR BETA3(071102) ROM에만 적용합니다. ROM·세이브·BIOS는 포함하지 않습니다. Python 3로 다음 명령을 실행하세요.

```text
python apply_ffr_v09c.py "BETA3(071102).gba" --output "검증판.gba"
```

이미 패치된 ROM, 다른 원본, 기존 출력 파일은 거부합니다. 현재 세이브는 백업하고 복사본으로 시험하세요. 원 게임·FFR 자료의 권리 범위와 고지는 RIGHTS.md를 따릅니다. 이 프리릴리스 승인은 원 게임 ROM 재배포 승인이나 실기 검증 완료를 의미하지 않습니다.

검증 범위는 V09C_PC_TEST_NOTES.md, 실기 확인은 HARDWARE_RETEST.md를 참고하세요.
