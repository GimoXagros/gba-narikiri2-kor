# v0.9c 프리릴리스 검증 범위

PC_VALIDATION_PASS / USER_AUTHORIZED_PRERELEASE / AWAITING_USER_HARDWARE_RETEST.

동결한 v0.9b와 후보 ROM/BPS를 각각 두 번 빌드해 동일성을 확인했습니다. 게임 바이트 변경은 0이며 EEPROM·대형 글꼴·음성을 보존합니다. 기존 전체 테스트 139개에 11개를 추가한 150개와 공개 계약 검사 49개가 통과했습니다. 적용기의 안내 문구와 명시적 프리릴리스 패키징 경로를 추가한 뒤에도 전체 검사를 다시 실행했습니다. 배포 패키지는 두 번 생성해 동일성과 독립 적용을 확인합니다.

mGBA에서 기준선·후보 각각 14경로/134화면을 재현했습니다. 아이템 156종/157화면, 코스튬 200종, 몬스터 142종, 인물 22명, 의상 기술명 224종과 기술 설명 231화면을 검사했습니다. 도감·기술 전체 표시 검사는 격리된 RAM 시험 상태를 사용하며 자연 해금 검증과 구별합니다.

수정한 오류는 ND2-V09C-20260909-001(불완전한 최종 출력), 002(manifest 검증), 003(이름 1227필드와 첫 단계 절대 포인터 2077개 표기 구분)입니다. 동일한 쓰기 실패와 잘못된 metadata를 사용한 수정 전 FAIL/수정 후 PASS 회귀검사가 있습니다.

동봉한 v0.9c.json은 e2303fb 단계의 PC 후보 기록입니다. 이후 사용자 공개 승인·최신 도구 출처는 v0.9c-prerelease.json이 보충합니다. 후보 당시 RELEASE_NOT_AUTHORIZED 표시는 당시의 상태이며 현재 프리릴리스 요청으로 갱신됐습니다.

실기·플래시카트·모든 이야기 분기·2기기 통신은 미검증입니다. 이번 감사가 전체 8037개 대사의 새로운 독립 문학 검수였다고 주장하지 않습니다. issue #4와 실기 재검증은 계속 열어 둡니다.
