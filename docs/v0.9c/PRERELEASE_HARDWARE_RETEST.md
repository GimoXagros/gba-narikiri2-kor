# v0.9c 실기 재검증

프리릴리스는 사용자 요청으로 공개됐으며 실기 검증은 아직 대기 중입니다. 원본 세이브를 백업하고 복사본을 사용하세요.

- ND2-V09C-20260909-001: 적용된 ROM의 SHA-256을 확인하고 새 게임→첫 저장→완전 종료→두 번 재시작을 시험합니다. 저장 공간 부족 오류 처리는 PC 도구 검사입니다.
- ND2-V09C-20260909-002: 사용한 ZIP/manifest/체크섬과 기기·실행기·저장 장치를 기록합니다.
- ND2-V09C-20260909-003: 이름 1227필드/절대 포인터 2077개 구분을 참고하고 이름·아이템·도감 표시를 확인합니다.
- 훌리오/캐로, 한글 6칸·혼합 이름, 기존 세이브 복사본 재저장, 중단 저장→재개→사용 후 상태를 확인합니다.
- 스펙터클즈·필리아 적 정보창, 전투 복귀, 기술 설명, 상점·의상 교환을 확인합니다. 두 기기 통신은 별도 검증이 필요합니다.

문제 발생 시 ROM 해시, 장치 정보, 재현 경로와 실제 화면을 함께 알려 주세요. 실기 결과 전에는 VERIFIED_HARDWARE 또는 v1.0 완료로 표시하거나 issue #4를 닫지 않습니다.
