# v1.1b — 반각 공백과 소형 목록 성능

일반 대사의 단어 간격을 12px에서 6px로, 지원되는 소형 문자열의 간격을 8px에서 4px로 조정했습니다. 글리프 자체의 폭은 유지합니다. 원래 느낌을 유지한 `아니요` 그래픽도 반영했습니다.

숫자 정렬, 들여쓰기, 이름 입력판, 사용자 지정 이름은 일괄 반각화하지 않습니다. 소형 공백 683개는 일반 단어 362개를 4px로 처리하고, 숨겨진 개발용 경로 126개·숫자 구분 12개·정렬 83개·입력판 100개는 원래 폭을 보존합니다. 숨겨진 16행 목록은 실제 64슬롯 캐시 용량 때문에 원래 처리기를 사용합니다.

ROM은 8,388,608바이트이며 10,371개 포인터와 문자열 시작 위치를 유지합니다. 종료된 문자열 뒤의 공간을 사용하는 코드에는 소유 영역·현재 압축 데이터·디코더 읽기 경계 검사를 적용했습니다. 기존 ROM 및 개인 저장은 수정하지 않았습니다.

## 최종 후보 검증

최종 ROM SHA-256: `32ed708c0c8c26074829a163000dd5504a5a7a1fbcd4f1319c2eb1f45d438677`

일본어 원본용 BPS SHA-256: `98e885adbc075ff0e953abb6e49dd5e03cd12dd07c755e9e7dde230408446eaf` (383,084바이트).

같은 입력을 명시한 원래 작업 폴더와 분리된 소스 폴더에서 ROM과 BPS가 바이트 단위로 재현되었습니다. 8,947개 실제 CPU 디코더 호출, 보호 문자열 45곳, 단계별 기록 영역과 변경되지 않은 영역을 독립 검사했습니다. CPU fixture와 가상 실행은 실기 시험과 구분합니다.

가상 실행에서는 기본 이름·혼합 사용자 이름의 게임 내 저장, 새 프로세스에서 두 번 불러오기, 다시 저장하기, 중단 저장의 생성·재개·소비를 확인했습니다. 펍 로즈의 기존 멈춤 장면은 별도 VBA 코어에서 31회 대사를 진행하고, 최종 ROM 전용 SGM을 역변환하여 새 프로세스에서 추가 8회 진행했습니다. SGM의 데스크톱 UI 로드는 시험하지 않았습니다.

`아니요`의 5개 상태와 전투 진입·기술 설정·전략 화면을 원본 해상도 및 정수배 화면으로 검토했습니다. 242개 그래픽 전체를 개선했다거나 게임 전체를 통과했다는 의미는 아닙니다.

## 확인된 한계

- 기술 버튼 설정 화면의 상단 제목 잘림은 이전 H3 후보에서도 동일합니다. 이번 버전에서 해결했다고 기록하지 않습니다.
- 오디오는 1,500,002개 스테레오 프레임 중 1개가 기준선과 다릅니다(13.838초, 좌우 변화량 −576/−192). 최종본 반복 실행은 동일하며 길이·콜백 수와 나머지 샘플은 같습니다. 원인 인과관계 및 청취 검증은 미완료이며 비트 단위 동일 판정은 하지 않습니다.
- 최종 v1.1b 실기, 전체 분기·장시간 전편 진행, 통신 플레이는 미검증입니다. 이전 버전의 사용자 검수는 이번 ROM의 실기 통과로 승계하지 않습니다. 이슈 #4를 유지합니다.

사용자는 최종 검증 후 배포를 조건부로 요청했습니다. 이는 `USER_REQUESTED_CONDITIONAL`이며, v1.1b 최종 파일에 대한 사용자 수락은 `NOT_REPORTED`, 실기는 `NOT_RUN`입니다. 공개 다운로드·새 폴더 재적용 기록은 별도 배포 기록에서 확인합니다.
