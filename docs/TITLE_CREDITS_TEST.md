# 한국어 타이틀·엔딩 크레딧 테스트

사용자가 비교 자료로 제공한 기존 한국어 타이틀의 `테일즈 오브 더 월드` 리본과 뒤쪽 문양을 보존했다. 아래 본문에서는 기존 `나리키리던젼`을 `나리키리 던전`으로 고쳤다. 원래 글자의 금색 면을 재사용해 단어 간격을 만들었으며 마지막 `젼`의 모음 윗획을 제거해 `전`으로 교정했다. 파란 입체 테두리와 그림자를 새 글자 위치에 맞췄다. 흰 테두리를 담은 별도 레이어에서 이전 글자 윤곽을 제거하고 수정된 글자·파란 그림자로부터 2px 테두리를 다시 만들었다. 같은 레이어에 있는 문양의 흰 내부·청록색 세부 픽셀 및 그 2px 가장자리는 보존한다. 리본 타일과 변경 범위 밖 픽셀은 보존했다. 후속 요청에 따라 숫자 2는 일본어 원본의 파란색 음영을 복원하고 불필요한 주변 픽셀을 제거했으며, 최종 지정된 오른쪽 시안 H와 동일한 얇은 흰 윤곽선을 사용했다. 흰 레이어는 H와 전체 픽셀이 일치하고, 글자·숫자·® 및 리본 레이어는 왼쪽 시안 I와 전체 픽셀이 일치함을 확인했다. ®도 원본 픽셀을 추출하여 마지막 전의 ㄴ과 2 사이의 기존 위치(184~190,75~83)에 배치했다. 주변 일본어 글자는 복사 범위에서 제외했다. 이 추가 변경은 두 기호의 지정 영역으로 한정하며, 그 외 모든 로고 픽셀이 r3와 일치하는지 확인했다.

저작권자 표기는 사용자 지정대로 `© 이노마타 무츠미  © 후지시마 코스케`이다. 두 © 뒤에 각각 한 칸을 넣었다. 사용자가 선택한 오른쪽 시안과 같은 달무리 8px 흰 글자·검은 외곽선·중앙 배치를 사용하며 하단 연도·회사·영문 권리 표시는 원본 픽셀을 보존했다. 고정 글리프는 `config/title_copyright_glyphs.json`, 달무리 출처와 라이선스는 기존 `third_party/dalmoori-font/`를 따른다.

스탭롤은 원래 191개 행과 순서를 모두 보존한 뒤 NAMCO, YOICHI HARAGUCHI, KYUSHIRO TAKAGI, MASAYA NAKAMURA 다음에 빈 줄 두 개와 다음 세 줄을 덧붙였다.

```
KOREAN TRANSLATION
TEAM FFR
XAGROS
```

테이블의 원래 단일 소비자는 `0x080A5688`이며 `0xA56E8`의 절대 주소를 통해 문자열 포인터를 읽는다. 새 테이블은 기존 ROM 끝 이후 `0xC85000`에 놓고 마지막 0 포인터를 보존했다. 마지막 스크롤 구간의 `movs r1,#53`만 `movs r1,#58`로 바꿔 추가된 다섯 행만큼 원래의 끝 여백을 유지한다. 명령 위치는 `0xA5316`이다. 후속 스탭롤 복원에서는 아래의 엔딩 전용 글꼴 훅을 추가했다.

## 검증

- 최종 ROM SHA-256: `8cf942048d4d03e37775bf5234733a5c049f8210e285173e7876a47db857e0ec`.
- 일본어 원본용 BPS SHA-256: `b8c93c519c5b609785f2d2e0b6f972a4dfc8a4aa3bbf49a269c078c9467900b0`.
- 고정 BETA2/BETA3/일본어 원본부터 재빌드한 결과가 v0.9d 기반 증분 빌드와 같다. 패치 사용자는 일본어 원본만 필요하다.
- 저작권 글자 범위, 누락 글자 거부, 원래 스탭 행 보존·추가 순서, 리본·문양·하단 영어 행 보존, 단어 사이 공백·전의 모음 획 교정, 이전 흰 테두리 잔상 제거·새 가장자리 생성, 일본어 BPS 왕복 및 잘못된 입력 거부 등 6개 계약 시험 통과.
- mGBA에서 최종 ROM을 직접 부팅해 타이틀 및 처음부터 화면을 확인했다. 변경한 그래픽 두 개가 실제 OBJ VRAM에 그대로 적재된 것을 확인했다.
- 엔딩은 부팅 함수 테이블 한 곳을 원래 엔딩 함수로 바꾼 별도 검증용 ROM으로 진입했다. 전체 스탭롤을 실행하여 기존 마지막 세 이름과 추가 세 줄이 실제 화면 타일맵에 적재되는 것을 확인했고, 초기 검증은 행 적재만 확인해 글꼴 손상 판독을 놓쳤다. 후속 복원에서는 원본 ASCII 글꼴 8192바이트 전체가 실제 VRAM과 같은지 추가 검사하고, 하이픈·괄호·영문 및 클리어 데이터 저장 질문 화면을 다시 확인했다. 자연스러운 전편 진행이나 클리어 저장 호환성을 이번 검사의 결과로 주장하지 않는다. 제공하는 플레이용 ROM에는 이 검증용 진입 변경이 없다.

이번 결과는 로컬 테스트용이다. 기존 공개 v0.9d 파일은 교체하지 않았다.

## 2026-09-20 스탭롤 글꼴 복원 및 수동 테스트 파일

원본 191개 행의 문자열과 순서는 일본어 ROM과 동일했다. 원인은 공용 8px 글꼴이 한글 UI용으로 바뀐 뒤, ASCII 타일 번호를 사용하는 스탭롤에서도 같은 글꼴을 참조한 것이었다. 따라서 하이픈이 E처럼, 괄호가 다른 기호처럼 보였다.

엔딩 페이지 초기화 0x080A59CC에 Thumb 진입 훅을 넣고, 0xC86F00의 래퍼가 원본 압축 글꼴(0xCA3F4, 1997바이트)을 복사한 0xC86000에서 0x080033AC 해제 함수를 호출한다. 목적지는 기존 포인터 0x03000050을 사용한다. 기존 명령과 LR/스택을 복구한 뒤 0x080A59D5로 복귀한다. 메뉴 공용 글꼴 포인터 0x2158/0x21D4는 바꾸지 않는다.

최종 전체 빌드와 증분 빌드는 일치한다. 타이틀 리소스는 승인된 r7과 동일하다. mGBA에서 엔딩 글꼴 8192바이트 전체 일치, VBA-M libretro에서 기호 및 추가 크레딧 화면을 확인했다. 일반 8KiB 저장도 마을까지 불러왔다.

사용자가 직접 테스트한다고 요청하여 데스크톱 UI 조작을 중단했다. VBA-M libretro 2.1.3 115defb의 버전 10 상태를 일반 테스트 ROM에서 재개·재저장했다. VBA-M 2.2.3의 공개 직렬화 코드에 맞춰 끝의 48바이트 RTC 앞에 0개 치트와 16384×84바이트 빈 치트 배열을 추가하고 gzip으로 SGM을 만들었다. 역변환 동일성과 코어 재로딩을 확인했다. 데스크톱 VBA-M 2.2.3의 SGM 로딩은 사용자 확인 대상으로 남는다. 이전 VBA 버전 호환성은 주장하지 않는다. 저장 상태 호환성에 의존하지 않는 별도 엔딩 바로보기 ROM도 제공한다.

이 엔딩 상태는 엔딩 감상용 진입으로 만들었으며 정상 진행의 클리어 세이브가 아니다. 일반 SAV는 기존 v0.9d 테스트 저장의 복사본이고 엔딩 직전 저장이 아니다. 엔딩 종료 시 클리어 저장은 하지 않는다. 공개 배포 파일은 이번 로컬 테스트로 교체하지 않았다.
