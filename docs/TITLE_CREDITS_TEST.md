# 한국어 타이틀·엔딩 크레딧 테스트

사용자가 비교 자료로 제공한 기존 한국어 타이틀의 `테일즈 오브 더 월드` 리본과 뒤쪽 문양을 보존했다. 아래 본문에서는 기존 `나리키리던젼`을 `나리키리 던전`으로 고쳤다. 원래 글자의 금색 면을 재사용해 단어 간격을 만들었으며 마지막 `젼`의 모음 윗획을 제거해 `전`으로 교정했다. 파란 입체 테두리와 그림자를 새 글자 위치에 맞췄다. 흰 테두리를 담은 별도 레이어에서 이전 글자 윤곽을 제거하고 수정된 글자·파란 그림자로부터 2px 테두리를 다시 만들었다. 같은 레이어에 있는 문양의 흰 내부·청록색 세부 픽셀 및 그 2px 가장자리는 보존한다. 리본 타일과 변경 범위 밖 픽셀은 보존했다. 후속 요청에 따라 숫자 2는 일본어 원본의 파란색 음영을 복원하고 불필요한 주변 픽셀을 제거했으며, 1px 흰 테두리로 정리했다. ®는 원과 R이 읽히도록 9×9 픽셀로 다시 작성하고 2의 왼쪽 아래에 분리해 배치했다. 이 추가 변경은 두 기호의 지정 영역으로 한정하며, 그 외 모든 로고 픽셀이 r3와 일치하는지 확인했다.

저작권자 표기는 사용자 지정대로 `© 이노마타 무츠미  © 후지시마 코스케`이다. 두 © 뒤에 각각 한 칸을 넣었다. 사용자가 선택한 오른쪽 시안과 같은 달무리 8px 흰 글자·검은 외곽선·중앙 배치를 사용하며 하단 연도·회사·영문 권리 표시는 원본 픽셀을 보존했다. 고정 글리프는 `config/title_copyright_glyphs.json`, 달무리 출처와 라이선스는 기존 `third_party/dalmoori-font/`를 따른다.

스탭롤은 원래 191개 행과 순서를 모두 보존한 뒤 NAMCO, YOICHI HARAGUCHI, KYUSHIRO TAKAGI, MASAYA NAKAMURA 다음에 빈 줄 두 개와 다음 세 줄을 덧붙였다.

```
KOREAN TRANSLATION
TEAM FFR
XAGROS
```

테이블의 원래 단일 소비자는 `0x080A5688`이며 `0xA56E8`의 절대 주소를 통해 문자열 포인터를 읽는다. 새 테이블은 기존 ROM 끝 이후 `0xC85000`에 놓고 마지막 0 포인터를 보존했다. 마지막 스크롤 구간의 `movs r1,#53`만 `movs r1,#58`로 바꿔 추가된 다섯 행만큼 원래의 끝 여백을 유지한다. 명령 위치는 `0xA5316`이며 코드 훅은 추가하지 않았다.

## 검증

- 최종 ROM SHA-256: `634ba569513c97967474db3c9b26a21aba6bef6fd2fa435869543ecd6cac3dc9`.
- 일본어 원본용 BPS SHA-256: `19b84ebd6f52c225437b20fbf09fd8331f99e635e8a5820e04e5fadd4cbcce04`.
- 고정 BETA2/BETA3/일본어 원본부터 재빌드한 결과가 v0.9d 기반 증분 빌드와 같다. 패치 사용자는 일본어 원본만 필요하다.
- 저작권 글자 범위, 누락 글자 거부, 원래 스탭 행 보존·추가 순서, 리본·문양·하단 영어 행 보존, 단어 사이 공백·전의 모음 획 교정, 이전 흰 테두리 잔상 제거·새 가장자리 생성, 일본어 BPS 왕복 및 잘못된 입력 거부 등 5개 계약 시험 통과.
- mGBA에서 최종 ROM을 직접 부팅해 타이틀 및 처음부터 화면을 확인했다. 변경한 그래픽 두 개가 실제 OBJ VRAM에 그대로 적재된 것을 확인했다.
- 엔딩은 부팅 함수 테이블 한 곳을 원래 엔딩 함수로 바꾼 별도 검증용 ROM으로 진입했다. 전체 스탭롤을 실행하여 기존 마지막 세 이름과 추가 세 줄이 실제 화면 타일맵에 적재되는 것을 확인했고, 화면 검토에서 정상 표시·스크롤 및 클리어 데이터 저장 질문으로의 전환을 확인했다. 자연스러운 전편 진행이나 클리어 저장 호환성을 이번 검사의 결과로 주장하지 않는다. 제공하는 플레이용 ROM에는 이 검증용 진입 변경이 없다.

이번 결과는 로컬 테스트용이다. 기존 공개 v0.9d 파일은 교체하지 않았다.

## 재현

```powershell
python tools/build_title_credits.py --beta2-reference BETA2.gba --beta3 BETA3.gba --japanese Japanese.gba --out-dir output/title-credits
python -m unittest discover -s tests -p test_title_credits.py -v
python tools/verify_title_credits_runtime.py --rom output/title-credits/Xagros_Narikiri2_KOR_title_credits_test.gba --core mgba_libretro.dll --out-dir output/title-credits-runtime
```

런타임 도구는 새 출력 폴더만 사용하며 에뮬레이터·ROM·검증용 ROM 해시와 진입 변경을 보고서에 남긴다. 화면의 미관과 글자 판독은 캡처를 직접 검토해야 한다.
