# v1.1 — 8MiB 원본 주소 복구 및 목록 성능 개선

확장 ROM을 읽던 텍스트·폰트·화면 자원을 정확히 8MiB 안에 통합했습니다.
원래 텍스트 포인터 10,172개·시작 위치 9,246곳과 채택한 한국어 출력은 유지합니다.
공유 주소의 서로 다른 문구는 원래 게임 호출 문맥으로 선택합니다.

압축 텍스트를 일반 문자열로 읽던 대사·이름·호칭·전투 알림·길이 비교 경로를 연결하고,
저장할 이름을 원래 필드 안에 복원하도록 수정했습니다. 타일 검색과 글자 합성은 기존
코드 공간·스택 안에서 개선했습니다. 새 RAM·저장 필드는 추가하지 않았습니다.
최적화 도중 발생했던 연속 선택/저장 상태 복귀 차이는 최종 후보로 재검사했습니다.

동일 입력 5회씩의 목록 P99는 아이템 8·도감 8·구매 7·판매 7·의상 7·캐릭터 17프레임입니다.
ROM SHA-256은 `9fd341b827a8ba282781d7f8f214f2ba8641365b541564d53e9ef5267511889b`입니다.
새/기존 일반 저장·중단 저장·콜드 로드·같은 ROM의 SGM은 가상 코어에서 확인했습니다.

2026-10-11 사용자는 직전에 전달한 8MiB 검증본의 정상 동작을 확인하고 v1.1 공개를 요청했습니다. 이를 해당 검증본에 연결한 USER_ATTESTED 공개 범위 결정으로 기록합니다. 기기·실행 프로그램·항목별 시험 내역과 사용자가 직접 대조한 해시는 별도로 보고되지 않았습니다. 이전 v1.0의 OLD 2DS 검수 기록을 이번 버전의 실기 증거로 옮기지 않습니다.

전체 자연 진행·모든 분기·통신·다른 코어의 SGM 호환을 보증하지 않습니다.
채택본부터 있던 지도 자원 32/43의 RL 연구 항목은 기존 바이트를 보존하며 별도로 남깁니다.
