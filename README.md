# Xagros의 한글화 패치 — 나리키리 던전 2

일본어 원본 ROM(게임 코드 AN9J)에 직접 적용합니다. FFR 패치를 먼저 적용할 필요는 없습니다. 현재 v1.0은 배포 조건 확인 중인 로컬 후보이며, 최종 검증 후보 ROM과 바이트가 같습니다. 공개 v0.9d ROM과는 바이트가 다릅니다.

## 적용

비공개 v1.0 후보 패키지를 풀고 Python 3.10 이상에서 실행하십시오. 추가 Python 패키지는 필요하지 않습니다. 공개 배포가 확정되기 전에는 [v0.9d 검증판](https://github.com/GimoXagros/gba-narikiri2-kor/releases/tag/v0.9d)이 최신입니다.

```powershell
python apply_japanese_patch.py "일본어 원본.gba" --output "Xagros_Narikiri2_KOR_v1.0.gba"
```

일본어 원본(AN9J): 8,388,608 bytes, SHA-256 `a92c0f6dbb5c013b47b7178e23d81663e3952a10df7b1f68967ebf7bb3b98eb7`.
최종 ROM: 13,270,790 bytes, SHA-256 `7505ef506e4fc11e1e0f36672956627e7522d2441cedfb06a5f359e7f5bd2b50`.
일본어 원본용 BPS: 5,045,193 bytes, SHA-256 `8d4a102714dccca1228215d97ae38b55eaca7ed9b74552150d3ab6aee2fa16e6`.

비공개 패키지의 새 폴더 재적용은 통과했습니다. 공개 릴리스의 외부 manifest와 다운로드 재검증은 배포 조건이 충족된 뒤 진행합니다.

## v1.0 변경

v1.0 후보는 두 번의 새 전체 체인 빌드에서 일치했고 직전 최종 검증 후보와 ROM 바이트가 같습니다. 한국어 타이틀/로고의 숫자 2와 ® 다듬기, 엔딩 스탭롤 ASCII 글꼴 복원과 FFR/XAGROS 크레딧·감사 문구, 부팅 안내, 22개 장소 표기와 훈다르크 표기, 17개 힌트와 CP #44 머리글, 156개 아이템·142개 몬스터 설명 검토, 대사 교정을 포함합니다. 본문 8,037개 고유 ID / 8,945개 바인딩 및 이름/UI 1,227개를 원문과 대조했고 60개 본문 ID / 98개 바인딩을 교정했습니다.

## 저장 및 확인 범위

기존 8 KiB 게임 내 저장을 사용하기 전 SAV를 백업하고 ROM/SAV의 파일명을 확장자를 제외하고 맞추십시오. 다른 ROM의 강제저장(savestate)은 재사용하지 마십시오. 세이브 호환 시험의 최종 범위와 누락 항목은 동봉 검증 문서를 확인하십시오.

**USER_ATTESTED:** “기존 대사 번역 단계에서 부터 20시간 정도 플레이를 하였고 막히는 레벨링 구간 및 도감 확인에는 치트도 사용하였습니다. 기존 세이브 파일과 진행하는데 이상 없이 이어졌습니다”. 사용자는 OLD 2DS + DSPico + GBARunner3에서 기존 저장으로 스탭롤까지 진행했다고도 보고했습니다. 자동 기기 로그가 아니며, 치트를 사용한 구간을 포함합니다. 자연 해금, 새 게임부터의 완주, 모든 분기 또는 최종 후보 ROM SHA와의 명시적 연결을 입증하지 않습니다.

자동 검사는 [v1.0 후보 검증 기록](verification/v1.0.json)의 실제 집계를 따릅니다. 전체 진행 진술과 자동 검사 결과를 구별하십시오. [적용 안내](docs/V1_PACKAGE.md) · [빌드 안내](docs/V1_BUILD.md) · [후보 릴리스 노트](docs/RELEASE_NOTES_V1.md)
